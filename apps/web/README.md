# @watchman/web

The Watchman web app: Next.js with the App Router and TypeScript. At the bootstrap stage this is the
clean `create-next-app` starter; the dashboard tiles arrive in later pull requests.

Run it from the repository root (npm only):

```bash
npm ci
npm run dev:web          # http://localhost:3000
npm run build            # production build
```

See the [root README](../../README.md) for the whole monorepo and its public-repo safeguards.
