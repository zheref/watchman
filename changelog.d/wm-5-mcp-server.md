- **Read-only MCP server**: `packages/mcp` serves four tools over stdio, `get_attention`, `get_flow`, `get_spend` and `get_metrics`, built on the official MCP TypeScript SDK v2 (`@modelcontextprotocol/server`). They read the same snapshot as the web app through `packages/core` (the newest usable `snapshot-<ISO>.json` in `WATCHMAN_SNAPSHOT_DIR`, else the labelled synthetic fixture) and make no network call. Each tool is annotated read-only and takes a validated `project` and `since`/`window` filter. Each answers compact JSON with `source` and `as_of` at the top level, an explicit `no_data` with a reason for anything missing, and `manual` on typed-in figures. A test pins the tool list to exactly these four. The entry refuses any transport but stdio and passes the existing loopback/auth guard. `packages/mcp/CONTRACT.md` documents every tool's schemas, an example call and a synthetic response, generated from the running server and kept in step by a test. Run it with `npm run --silent mcp` or the `watchman-mcp` bin. `packages/core` gains the pure filter helpers `parseWindow`, `resolveSince`, `isAtOrAfter`, `matchesProject`, `normalizeProject` and `FilterError`, plus `resolveSnapshotSource` and `unavailableSnapshot`, which hold the fixture-or-directory rule with the file system injected (zheref/watchman#5).
