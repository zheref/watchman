- **Mobile Attention tile**: `apps/mobile` is now an Expo Router app (SDK 58) that shows the Attention tile from the bundled synthetic fixture: the top five ranked items, each with its source and as-of time and a deep link opened with `Linking.openURL`, a visible "synthetic" badge, and a labelled "No data" state. Ranking, validation and provenance come from `@watchman/core` through the npm workspace (no copy, no `metro.config.js`); the Metro look is plain React Native styles with accessible roles and labels. `npm run build` now also runs `expo export` for iOS and Android, headless, and `apps/mobile` joins the Vitest run with a unit-tested view-model (zheref/watchman#6).
