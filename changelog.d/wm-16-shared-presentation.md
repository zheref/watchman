- **One set of presentation helpers for web and mobile**: `KIND_LABEL`, `waitedLabel` and `linkHost` now live once, in a new workspace package `packages/ui` (`@watchman/ui`, the shared presentation layer), and both apps import them; each app's own copy is gone. `linkHost` had drifted (the web copy used `new URL(...).hostname`, which throws on bad input; the mobile copy used a regular expression, which returned `user@host` for a link with a user part). It now has one behaviour on both apps: it never throws, it never shows a user part (the host is what follows the last `@`, as a browser reads it), it answers lower-case with no port, and it gives an empty string for anything that is not an `https` link to a dotted ASCII host name. A new `linkDestination` prints that host, or "another site" when it cannot be read, so no screen says "opens" with nothing after it. One table of 41 links pins the behaviour in the package and in each app's tests.
